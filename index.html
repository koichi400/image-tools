掘り下げ：6つの道具

「画像ツール」と一言で言っても困りごとは別々です。このツール箱は、よくある6つの作業を1つの画面にまとめています。

📱

HEIC → JPG 変換

iPhoneの標準形式HEICは、Windows・役所・古いシステムで開けないことが多い定番トラブル。

  • HEIC / HEIF に対応
  • まとめて一括変換
  • 向き（回転情報）も自動補正
🗜️

画像圧縮

画質スライダーと「目標KB以下」で、アップロード制限に合わせます。

  • 画質 30〜100% を調整
  • 200KB / 500KB / 1MB / 2MB 目標
  • 変換前後のサイズをその場で比較
📐

リサイズ・切り抜き（Crop）

長辺を指定するだけ。アスペクト比は自動で維持され、引き伸ばしはしません。不要な部分は切り抜きで取り除けます。

  • 3840 / 1920 / 1280 / 800 / 400px
  • カードの「✂」からドラッグで範囲指定
  • 1:1 / 4:3 / 16:9 など比率プリセット付き
  • 元より大きくはしません
🔄

形式変換 JPG / PNG / WebP

用途で使い分け。WebPはJPGより軽く、PNGは透過と文字の鮮明さが強み。

  • JPG：互換性No.1・提出用
  • PNG：透過・ロゴ・スクショ
  • WebP：Web掲載で最軽量
🔃

回転・補正

横向きになってしまった写真は、カードの回転ボタンで90°ずつ直してから保存。

  • 1枚ずつ回転OK
  • EXIFの向きも考慮
  • 再圧縮せずにプレビュー反映
🛡️

EXIF・位置情報の削除

写真には撮影場所のGPSが入っていることがあります。Canvasで再描画することで自動除去。

  • GPS・機種・日時を除去
  • SNS・フリマ出品前に安心
  • オン／オフ切り替え可能

こんなときに

プリセットを選ぶだけで、その用途に合った設定になります。

1

役所・ビザ・応募書類にアップロードしたい

「JPGのみ・2MBまで」といった制限に。長辺1920px＋JPGでほぼ確実に通ります。

2

iPhone写真をWindowsの家族に送りたい

HEICのままだと相手が開けません。JPGに変換してZIPでまとめて渡せます。

3

ブログ・サイトを軽くしたい

WebP＋1280px＋画質80%前後で、見た目をほぼ保ったまま容量を大幅削減。

4

フリマ・SNS投稿前に位置情報を消したい

自宅で撮った写真のGPS除去が目的。EXIF削除オン＋そのまま変換でOK。

形式の早見表

迷ったらJPG。軽さならWebP、透過や文字のくっきり感ならPNGです。

形式向いている用途容量注意点
JPG写真全般、提出書類、メール添付小さい透過不可。繰り返し保存で劣化
PNGスクリーンショット、ロゴ、透過画像大きい写真だと容量が膨らみがち
WebPWebサイト、ブログ、SNS最も小さい古いシステムでは開けない場合あり
HEICiPhone内の保存小さいWindows・Web提出では非対応が多い → JPGへ

よくある質問

画像はサーバーに送られますか？

いいえ。変換・圧縮・リサイズはすべてこのページのJavaScriptとCanvasで処理します。HEIC変換ライブラリもブラウザ内で動作するため、画像ファイル自体が外部に送信されることはありません。

HEICが変換できないときは？

一部のAndroid HEIFや、破損したファイルでは失敗することがあります。その場合は元の形式のまま表示されます。SafariではHEICを標準で読み込めるため、ブラウザを変えると成功する場合があります。

画質はどれくらいがおすすめ？

写真は85%がバランス良好です。提出書類は90〜95%、Web掲載なら75〜85%で十分なことが多く、容量を大きく減らせます。

まとめて保存（ZIP）の中身は？

変換後の画像を、元のファイル名＋形式でまとめたZIPです。例：IMG_1234.heic → IMG_1234.jpg

切り抜き（Crop）はどうやりますか？

各画像カードの「✂」ボタンを押すと切り抜き画面が開きます。枠をドラッグして位置と大きさを決め、「この範囲で切り抜く」を押してください。1:1や16:9などの比率プリセットも選べます。切り抜き後にリサイズ・回転・圧縮が適用されます。

切り抜き（Crop）

枠の中をドラッグで移動、四隅のハンドルをドラッグでサイズ変更できます。切り抜きは元の解像度で適用され、その後にリサイズ・回転・圧縮が行われます。
